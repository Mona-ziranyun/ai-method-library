# 自然云 AI 方法库

收录跑通过的 AI 和工具用法。每个方法写清楚步骤、要准备什么、容易踩的坑，能直接用的就配一个小工具。

- 页面：`index.html`（单文件，浏览器直接打开即可）
- 网页：https://mona-ziranyun.github.io/ai-method-library/

M-003 详情内提供主页链接转热点宝链接的生成器，可直接打开「数据趋势」。网址规则核对日期为 2026-11-05。

M-004 详情内提供作品链接转星图数据页的生成器。固定网址为 `https://www.xingtu.cn/ad/creator/insight/hot-video-detail/作品ID`，打开前需在同一浏览器登录星图。示例作品 `7291802072054336820` 于 2023-10-20 发布，2026-11-05 页面展示播放量为 `3.49w`；该展示值不作为精确次数，也不代表其他作品均可查询。
